# Security Policy

## Supported Versions

SiteCTX v0.1 is supported while the specification is in early release.

## Reporting Security-Sensitive Issues

Use GitHub private vulnerability reporting when it is enabled for this
repository.

If private vulnerability reporting is not enabled, do not include exploit
details, abuse procedures, private data, or sensitive operational information in
a public issue. Open a minimal public issue asking maintainers for a private
contact path, and include only enough context to route the report.

Ordinary specification clarifications, schema questions, documentation bugs, and
interoperability feedback should use regular Issues or Discussions.

Maintainers may move a report between public and private handling when needed to
protect users, publishers, consumers, or the integrity of the specification.
